# Zoe Charge Calculator

PWA (aplicação web instalável) para simular o carregamento de um Renault Zoe ZE50.

Configuração base:
- tensão de referência: 223 V
- correntes disponíveis no carregador: 8, 10, 13 e 16 A
- 8 A, 10 A, 13 A e 16 A calibrados com sessões reais
- todas as correntes disponíveis já têm uma calibração real
- janela predefinida: 00:00–07:00

Depois de publicado por HTTPS, pode ser instalado no Android através do Chrome e funciona offline após a primeira abertura.
